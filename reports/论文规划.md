# 论文规划：语音模型从 LLM 继承了什么

草稿，2026-11-07。依据：`Qwen3 结构与功能溯源实验.md`（下称“报告”）和 `experiments/` 下的原始输出。

## 一句话

同一家族里的语音模型和 LLM 是否“共用一个脑子”，要分开看：ASR 几乎整段共用，可以用 2-bit 残差挂在共享主干上；TTS 不共用上下文处理，线性拼接失败。但 LLM 的知识可以通过一个很窄的离散接口（读音头 + 读音码本）交给 TTS，用实际合成的音频和独立评委组验证。

## 可以写成的论文

**主线（推荐）：分析型论文。** 题目方向：“Shared backbone, separate minds? What Qwen3 speech models inherit from the LLM”。贡献：(1) 去 shrink 的家族权重图谱；(2) ASR 可作为共享主干上的低比特残差，TTS 不行；(3) 相似不等于可替换的因果证据；(4) 一个窄接口能把 LLM 的读音知识交给 TTS，并用独立评委组和盲听做端到端评测。适合 Interspeech 或 ACL/EMNLP 的分析类论文。负结果（B2、B5）是卖点之一，不需要包装成正结果。

**不推荐：方法型论文（“用 LLM 提升 TTS 多音字”）。** 已经比过，结论是否定的（B6）。在 CPP 上重训的 g2pW 少数读音 .900，LLM L8 读音头 .774；端到端 g2pW 加码本 .872，LLM 加码本 .795。这条路线可以关掉。

**g2pW 对照之后的调整（2026-11-08）：**
- 第 (4) 点的表述改为“窄的离散接口能修正 TTS 实际读音，而且不挑上游”。读音码本接上 g2pW 一样有效。
- “LLM 继承”在 B 线上整体变成负结果：线性拼接失败（B2），提示失败（第 6 步），读音头输给专门 G2P（B6）。只剩探针显示 LLM 状态里有读音信息（B3），但这不比一个专门模型更有用。
- 这让论文的主线更统一：ASR 真能共用主干（A2、B1）；TTS 不能，对 TTS 有用的是窄接口加专门前端，而不是 LLM。
- 读音码本本身（第 4 步，balanced .977）可以作为一个小的、正面的方法贡献：它让任何 G2P 的输出能直接控制一个没有显式音素输入的 TTS。

## 提示实验结果（报告第十节第 6 步）

不思考模式、零样本，Qwen3-0.6B/1.7B/4B 在 CPP 开发集上只有 .558–.587，少数读音 .46–.48，低于 TTS 自己的实际读音（.522），远低于读音头（.75–.77），规模变大也没有改善。预设判定：4B 不有用，没有超出 TTS 读音头，也没有超出探针。

对论文的意义：这是 B 线的另一个负结果，而且很干净。“让 LLM 说出读音再交给 TTS”这条路不通，只有在隐藏状态上接有监督的窄接口才有用。它把论文主张收窄成“LLM 表示可以被读出，但 LLM 本身不会读”，而不是“TTS 继承了 LLM 的推理”。思考模式（4B，探索性）是 .517，和 TTS 持平，仍比读音头低 .23–.26。推理过程能认出“征辟”是征召的意思，却把读音记反。

## 修订后的主张

1. ASR 和 LLM 在表示上共用整个主干（B1），漂移承载功能（A2）。但在真实端侧运行时上，“共享底座 + 2-bit 残差”打不过独立 Q4：准确率差约 1.3 个百分点，慢 34%，只省约 110 MB（A2，2026-11-08）。论文里要把这一点写成“模拟结论在真实量化器和内核下不成立”的教训，不能再说“可以共享省一半”。
2. TTS 不共用 LLM 的上下文处理：相似不等于可替换（B1、B2）。其他三个家族的 TTS 形状相同，但测量没有过正对照，只能作为旁证（B8）。如果要把它写成跨家族的规律，需要一个能过同家族正对照的相似度度量。
3. LLM 状态里有读音信息，但用语言问（不论是否思考）它答不对（B3、第 6 步）；读出来也比不过专门的 G2P（B6）。
4. 一个离散的窄接口（读音码本）足以修正 TTS 的实际读音，且不挑上游：LLM 读音头 .41 → .80，g2pW .41 → .87（B4、B6）。增益来自接口和监督，不来自 LLM（B5、B6）。
   端侧可部署：g2pW int8 加码本、全句改写，在 natural2 上不仅安全而且有提升（B7）；用户词典能覆盖 G2P 不会的专名读法。
5. 方法：独立 ASR 评委组加盲听，用来评测“TTS 实际读成了什么”（C1）。

这是一篇诚实的分析论文，结论偏向“继承比想象中少，而且要走窄接口”。“LLM 让 TTS 更好”的正结果在多音字上已经被 g2pW 否定。如果仍想要这个方向的正结果，需要换一个专门模型做不到、而 LLM 有优势的任务，例如需要长上下文或世界知识的韵律、专名读法、跨句指代。这得另开实验，不能从现有数据里挖。
