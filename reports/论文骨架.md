## 一句话主张

同一家族里，ASR 几乎完整继承了 LLM 的主干，TTS 只继承了浅层。LLM 的读音知识读得出来，但不会直接说；要把它交给 TTS，有用的是一个窄的离散接口加监督，而且专门的 G2P 比 LLM 本身更好。

## 摘要要点（约 200 词）

- 问题：同一家族的语音模型从 LLM 继承了什么？是共用一个脑子，还是只共用了初始化？
- 对象：Qwen3 家族（LLM、ASR、TTS 等 10 个同尺寸模型），外加三个其他家族的 LLM 初始化 TTS。
- 方法：去 shrink 的权重谱系、逐层表示相似度加随机对照、因果拼接、读音探针、实际合成音频加独立 ASR 评委组和人工听测。
- 发现：
  1. ASR 全深度共用主干，漂移承载功能；
  2. TTS 只共用浅层，线性拼接失败；
  3. LLM 状态里有读音信息，但提示它答不对；
  4. 一个读音码本接口能把任何 G2P 的输出交给 TTS，端侧管线把难题集少数读音从约一半提到约 85%；
  5. 但专门的 G2P 比 LLM 更好。
- 结论：继承比想象中少，而且只能走窄接口。

## 1 引言

- **动机**：语音模型越来越多地以 LLM 为底座，常见说法是它们“继承了 LLM 的知识”。这对部署（共享主干、共享内存）和方法（用 LLM 改进语音）都有含义，但很少有人分功能、分层、带因果地检验过。
- **问题**：
  1. 权重层面，谁从谁来？
  2. 表示层面，哪些层是共用的？
  3. 因果层面，共用的表示能互相替换吗？
  4. 知识层面，LLM 有用的知识能交给 TTS 吗，通过什么接口？
- **贡献**（4 条，对应第 4–7 节）：
  1. 去 shrink 的家族权重图谱：家族是树，不是围绕 Base 的星形（A1）。
  2. ASR 全深度共用 LLM 主干，TTS 只共用浅层；相似不等于可替换（B1、B2）。
  3. LLM 读音知识的“可读不可说”：探针读得出，提示答不对，专门 G2P 更好（B3、第 6 步、B6）。
  4. 读音码本：一个不挑上游的窄离散接口，加一个可部署的端侧管线，用评委组和人工听测做端到端评测（B4、B7、C1）。
- 负结果是卖点：B2、B5、B6、A2 后半都直接写，不包装成正结果。

## 2 相关工作 〔待调研〕

- 模型合并、task vector、delta 压缩：说明“delta 余弦”的 shrink 假象是新的提醒。
- 表示相似度：CKA 及其局限；大激活（massive activations）和注意力汇对线性 CKA 的影响（E7 的教训）。
- 基于 LLM 的语音模型：Qwen-Audio / Qwen3-ASR / Qwen3-TTS，CosyVoice 2、Spark-TTS、Llasa 等 LLM 初始化 TTS。
- 多音字消歧与 G2P：g2pW、CPP 数据集，以及基于 LLM 的 G2P。
- LLM 内部知识的探针与“知道但说不出”（probing、latent knowledge）。
- TTS 评测：ASR 回写、MOS / AB 测试，以及 ASR 作为读音评委的可靠性。

## 3 实验设置

- **模型**：
  - Qwen3 0.6B / 1.7B 家族：Base、Instruct、Guard、Embedding、Reranker、ASR、ForcedAligner、TTS-Base、TTS-CustomVoice 等（报告第一、三节）。
  - 跨家族：Llasa-1B（Llama-3.2-1B）、Spark-TTS（Qwen2.5-0.5B）、CosyVoice2 LM（Qwen2-0.5B-Instruct）。
- **数据**：
  - 文本语料：75 段，代码、文档、口语，中英。
  - 真实语音：AISHELL、FLEURS、方言集，共 800 条。
  - 多音字：CPP 难题集（少数读音 230、多数读音 90）、natural（76）、natural2（131）、用户词典集（21）。
- **读音评判**：
  - ASR 检测器：以 R_g、R_a 为中心的对数几率。
  - 三评委组：SenseVoice、Paraformer、Whisper 严格多数，只判声韵对比，并在真人音频上过了预设线（C1）。
  - 人工听测（第 7.6 节）。
- **统计**：按字分组的 bootstrap 95% CI；判据都在出数前写定，写进脚本开头。

## 4 权重谱系

- **4.1 去 shrink**：不去掉 shrink 时，delta 余弦会让无关的模型看起来相关；去掉后家族成树。同分支内距离 .005–.16，跨功能 .25 以上，TTS 与其他模型约 1.4–1.5（报告第三节）。
- **4.2 权重距离不等于功能距离**：ASR 离 Base 比 Instruct 远约 3 倍，在文本上的输出却更接近 Base（报告第三节）。
- **4.3 跨家族谱系**（E7）：三个 TTS 都从 LLM 出发，但改动很大，余弦 .20–.66，而同家族 Instruct 对 Base 是 .99。CosyVoice2 的 LM 实际来自 Qwen2-0.5B-Instruct。

## 5 ASR 继承了主干

- **5.1 表示**：文本路径 CKA 全深度 .91–.98；注意力匹配头 JS .04–.06，随机配对为 .35–.48（B1）。
- **5.2 漂移承载功能**：ASR 解码器可以写成 Base 上的 2-bit 残差；换成同范数噪声后错误率 100%（A2）。
- **5.3 共享主干在真实端侧不划算**：M4 + MLX 上比独立 Q4 差 +1.3 [+0.7, +1.9] 个百分点，慢 34%，只省约 110 MB（A2，报告第九节）。写成“模拟结论在真实量化器和内核下不成立”的教训。
- **5.4 结构**：首 token 尖峰和注意力汇是因果关键结构（A3），任务专属神经元有双重分离（A4）。这两点放附录或简述，已有文献。
- 图 2：逐层 CKA，ASR、TTS-0.6B、TTS-1.7B、随机对照。

## 6 TTS 没有继承上下文处理

- **6.1 浅层共享、深层分化**：TTS-0.6B（独立训练）和 TTS-1.7B（从 Base 出发）都是浅层 .6–.7、深层接近随机（B1）。
- **6.2 因果拼接**：LLM 状态经线性映射接入 talker，几乎恢复不了文本作用；阳性对照（TTS 之间互接）恢复 .93–.97（B2）。
- **6.3 跨家族旁证**：Llasa、Spark、CosyVoice2 的形状相同，但线性 CKA 受大激活影响，处理后同家族正对照仍未全过 .9，只作为旁证（B8）。

## 7 什么能交给 TTS：读音

- **7.1 LLM 里有读音信息**：探针优于 TTS 文本路径，CI 不含零（B3）。
- **7.2 但 LLM 不会说**：零样本提示 0.6B–4B 只有 .46–.48，低于 TTS 自己的 .522；思考模式 .517（第 6 步）。
- **7.3 读音码本接口**：读音头加码本，难题集少数读音 .41 → .80（B4）。增益主要来自读音头，LLM 只多约 6 个百分点（B5，探索性）。
- **7.4 专门 G2P 更好**：g2pW 比 LLM 读音头高 .126 [+.073, +.186]；经同一码本端到端 .41 → .87；两者的错误几乎不互补（B6）。
- **7.5 端侧管线**：g2pW int8（114 MB，每句 39 ms）→ 码本 → 不改动的 TTS。
  - 少数读音 +.326（检测器）、+.344（三评委）。
  - natural2：检测器 +.122，三评委 +.059，不显著。
  - 风险在同词邻字：v2 词级规则方向一致，但没过预设判据（B7）。
- **7.6 人工听测**（待做，见 `experiments/e8_listening/`）：O 对 P，至少 3 名母语听者，判 H3、H5，并校准 ASR 检测器。

## 8 方法上的教训（可并入讨论）

1. delta 余弦有 shrink 假象，要先去掉。
2. 模拟量化的结论在真实内核上可能不成立。
3. 跨模型比较时，线性 CKA 要先处理大激活，并且要有同家族的正对照。
4. ASR 评委只能判声韵，不能判声调和第三读音（C1）。

## 9 局限

- 因果结论（B2）只在 Qwen3 上做过。
- 读音只是一个试点任务；韵律、专名、跨句指代等 LLM 可能更有优势的任务没测。
- 金标没有第二标注者。
- 码本只覆盖 650 个读音里的 407 个。

## 10 结论

继承比想象中少：ASR 真能共用主干，TTS 不能。对 TTS 有用的，是窄接口加专门前端，而不是 LLM 本身。
