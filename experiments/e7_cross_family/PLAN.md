# E7 其他模型族：从 LLM 初始化的 TTS 是否也“浅层共享、深层分化”

2026-11-11 写定，在下载任何模型、算出任何数之前。

## 问题

Qwen3 里，TTS-1.7B 从 Base 出发，却几乎被重写：文本位置的 CKA 从 L2 的 .70 降到 L26 的 .12。TTS-0.6B 独立训练，结果也一样。这是 Qwen3-TTS 自己的设计造成的，还是“在 LLM 上训练 TTS”的一般规律？

换三个不同家族、不同语音 token 的 TTS 来检验：

| 代号 | TTS 模型 | 据称的底座（下载后用权重核实） | 语音 token |
|---|---|---|---|
| cosy | CosyVoice2-0.5B 的文本-语音 LM | Qwen2.5-0.5B | 监督式语义 token（来自 ASR 编码器） |
| spark | Spark-TTS-0.5B | Qwen2.5-0.5B | BiCodec（wav2vec 2.0 语义 + 全局 token） |
| llasa | Llasa-1B | Llama-3.2-1B（模型卡写的是 Instruct） | XCodec2 单码本 |

对比的 LLM：每个 TTS 都和 Base 与 Instruct 两个版本比，权重更近的那个算作它的底座。

## 第 1 步：权重（CPU 即可）

- **核实底座**：逐层、逐矩阵算去 shrink 残差 R = W − αB，取 ‖R‖/‖B‖ 更小的那个 LLM 作为底座。词表扩充的行不算。
- **随深度的变化**：报告每层的相对残差，以及它和层深的 Spearman 相关。
- **参照**：同一家族里 Instruct 相对 Base 的残差。

这一步只做描述，不设判据。

## 第 2 步：表示相似度（主判定）

- **输入**：沿用 E4 第 1 步的语料（`e2_activation/common.py` 的 75 段），按各 TTS 自己的文本前缀格式输入，只比较文本位置。
- **度量**：去偏线性 CKA，TTS 第 l 层对底座 LLM 第 l 层。
- **对照**：同结构的随机初始化网络（种子 0）、打乱 token 顺序。
- **分段**：前三分之一层的均值记为 S（浅层），后三分之一层的均值记为 D（深层），都不含 L0。

**每个模型的预设判定：**
- **可解释**：浅层 S 比同深度随机对照至少高 .2。不满足的模型记为“不可解释”，不参与家族判定。
- **深层分化**：D ≤ .5，且 S − D ≥ .2。
- **深层共享（像 ASR）**：D ≥ .8。
- 都不满足的记为“居中”。

**家族判定：**
- 三个可解释模型都是“深层分化”：结论写成“深层分化是 LLM 初始化 TTS 的普遍规律”。
- 任何一个是“深层共享”：结论写成“取决于设计，不是普遍规律”，并报告是哪一个。
- 其他情况：结论写成“不一致”，逐个报告。

**探索性，不设阈值：**
- CosyVoice2 的语音 token 由 ASR 监督得到，离文本更近，深层 CKA 是否更高。
- 线性重建 R²，两个方向都算。
- 和 Qwen3 TTS-0.6B、TTS-1.7B 的数值放在同一张表里。

## 第 3 步（待定）：因果拼接

只有第 2 步出现“深层共享”或“居中”时才做。做法和 E4 第 2 步相同：在第 k 层把文本位置换成岭回归映射后的 LLM 状态，用真实语音 token 做 teacher forcing，看下一个语音 token 的预测恢复多少。这一步需要先把各自的编解码器接好，等第 2 步出结果后再写判据。

## 算力

- AutoDL：先用无卡模式开机下载模型，再按需抢最便宜的卡（8–12 GB 就够；成本约每 8 GB 显存 1 元/小时）。
- 0.5–1B 的模型 bf16 只要 1–3 GB 显存，第 1、2 步预计 1–2 小时 GPU 时间。

## 第一轮结果（2026-11-11，AutoDL RTX 4080 SUPER；`remote_logs/`、`weights_results.json`、`cka_results.json`）

**第 1 步（权重，描述性）**：

| 模型 | 对比 | 去 shrink 相对残差（前/中/后三分之一） | 余弦 | 文本 embedding 行漂移中位数 |
|---|---|---|---|---|
| CosyVoice2 LM | Qwen2.5-0.5B Base | 1.78 / 1.84 / 1.89 | .000 | .44 |
| CosyVoice2 LM | 自带的 CosyVoice-BlankEN | 1.77 / 1.89 / 1.95 | .310 | .08 |
| CosyVoice-BlankEN | Qwen2.5-0.5B Base | .92 / .93 / .94 | .001 | .98 |
| Spark-TTS LM | Qwen2.5-0.5B Base | 6.90 / 7.37 / 7.15 | .200 | 4.62 |
| Llasa-1B | Llama-3.2-1B Base | .82 / .94 / .94 | .659 | .63 |
| Llasa-1B | Llama-3.2-1B-Instruct | .82 / .94 / .95 | .666 | .66 |
| 参照：Qwen2.5 Instruct | Base | .07 / .08 / .07 | .997 | .10 |
| 参照：Llama-3.2 Instruct | Base | .14 / .16 / .17 | .987 | .18 |

- CosyVoice2 的 LM 与 Qwen2.5-0.5B 权重余弦为 0；它自带的 CosyVoice-BlankEN 与 Qwen2.5-0.5B 也是 0。BlankEN 可能是别的底座（例如 Qwen2-0.5B），待核实。CosyVoice2 LM 从 BlankEN 出发（余弦 .31），文本 embedding 几乎没动（.08）。
- Spark-TTS 从 Qwen2.5-0.5B 出发（余弦 .20），但权重被放大、重写得很厉害。
- Llasa 从 Llama-3.2-1B 出发（余弦 .66），越深改得越多（ρ +.87）。离 Base 和 Instruct 一样远，分不出是哪一个。

**第 2 步（CKA）：预设判定作废。** 脚本按预设规则输出“general deep divergence”（只有 Llasa 可解释，判为深层分化；CosyVoice2 和 Spark 浅层不比随机高 .2，判为不可解释）。但测量本身没通过一个本该预设的正对照：Llama-3.2 的 Instruct 和 Base 权重余弦 .987，CKA 在 L2–L14 却只有 .03–.47。Qwen2.5 这边随机网络从 L3 起全部为 0，CosyVoice2 和 Spark 也都在 L3 突然掉到 .05 左右。最可能的原因是大激活（massive activations）：少数维度和 token 的数值极大，主导了线性 CKA。所以这一轮的 CKA 数字不能用来下结论。

## 第二轮判据（2026-11-11 写定，第二轮 CKA 算出之前）

用户同意后重跑第 2 步，改动只针对上面发现的测量问题：
- **处理大激活**（每层、每对模型）：
  - 两个模型各自算每个 token 的范数，任一模型里超过本层中位数 10 倍的 token，两边一起剔除（CKA 需要同一批行）。
  - 每个模型各自剔除均方根超过本层维度中位数 10 倍的维度。
  - 报告每层剔除了多少 token 和维度。
- **正对照（新增，测量有效的前提）**：处理后，两个家族的 Instruct 对 Base 每一层 CKA 都要 ≥ .9。任一家族不满足，第 2 步记为“测量无效”，不下家族判定。
- **其余不变**：S、D 的定义，“可解释”“深层分化”“深层共享”“居中”的阈值，家族判定规则，都和第一轮相同。
- **报告**：同时列出未处理的原始 CKA，便于对照。保存抽样后的各层特征（fp16），以便离线复算。
- **权重补充（描述性）**：加 Qwen2-0.5B 和 Qwen2-0.5B-Instruct，核实 CosyVoice-BlankEN 的底座。

## 第二轮结果（2026-11-11 14:56，同一台实例；`remote_logs/weights2.txt`、`remote_logs/cka2.txt`、`cka2_results.json`）

**权重**：CosyVoice-BlankEN 与 Qwen2-0.5B-Instruct 完全相同（相对残差 .000，余弦 1.000），与 Qwen2-0.5B Base 也几乎一样（.015）。所以 CosyVoice2 的 LM 是从 **Qwen2-0.5B-Instruct** 出发的（余弦 .31），不是公开资料常说的 Qwen2.5-0.5B。

**CKA 预设判定：测量无效。** 处理大激活后，正对照仍未通过：
- Qwen2.5：Instruct 对 Base 在 L1–L23 为 .97–1.00，只有最后一层 L24 是 .86。这一层被剔除的维度最多（11/14 个）。
- Llama-3.2：Instruct 对 Base 在 L9–L13 为 .79–.87，L15 只有 .67。

大激活的影响确实存在：Qwen2.5 每段的第一个文本 token 在 L3–L21 都被剔除了。剔除后随机对照从 0 恢复到 .09–.20，CosyVoice2 和 Spark 在 L3 的断崖也消失了。

**描述性结果（不能当判定用）：**

| 模型 | 比较对象 | 浅层 S | 深层 D | 随机对照 S | 按阈值归类 |
|---|---|---|---|---|---|
| Llasa-1B | Llama-3.2-1B Base | .56 | .20 | .16 | 深层分化 |
| Spark-TTS | Qwen2.5-0.5B Base | .37 | .19 | .11 | 居中（S − D = .18，差 .02 不到 .2） |
| CosyVoice2 | Qwen2.5-0.5B Base（比错了对象） | .41 | .23 | .11 | 居中 |

- 三个模型都是浅层最像 LLM，往深层单调下降，到最深几层接近随机对照。这和 Qwen3 TTS-0.6B、TTS-1.7B 的形状一致。
- CosyVoice2 这一行比错了对象：它的底座是 Qwen2-0.5B-Instruct，不是 Qwen2.5。要和正确的底座比，还得补跑一次。
