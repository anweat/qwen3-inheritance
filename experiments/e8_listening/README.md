# E8 多音字人工听测

验证论文的 H3（管线在 CPP 少数读音上有提升）和 H5（管线在 natural2 上安全），同时校准 ASR 检测器。抽样、页面和打分规则都在 2026-11-11 写定，那时还没有任何听者作答。细节写在 `make_page.py` 和 `score.py` 的开头。

## 文件

| 文件 | 用途 | 能否外发 |
|---|---|---|
| `listening.html` | 听测页面，7.7 MB，音频已内嵌，离线可用 | 发给听者 |
| `key.json` | 答案、版本（O/P/R_g/R_a）、检测器判定 | **不能外发**（会泄露答案） |
| `make_page.py` / `template.html` | 重建页面；抽样固定用 seed 11，重跑结果不变 | — |
| `score.py` | 打分和预设判定 | — |
| `answers/` | 把听者交回的 `listening_*.json` 放在这里 | — |

## 设计

- **句子**：40 句 CPP 少数读音（每个字组最多 1 句），30 句 natural2（每个字最多 2 句）。
- **每句两段音频**：原 TTS（O），以及 E6 管线（P）。另有 10 段已知读音的检查题（R_g、R_a 各 5 段）。合计 150 段。
- **页面**：
  - 高亮目标字，让听者选两个读音之一，或“都不像 / 听不清”。不显示版本、检测器判定，也不显示哪个是正确读音。
  - 题目顺序按听者名字打乱。同一句的 O 和 P 一个在前半、一个在后半，至少相隔 20 题。
  - 进度保存在浏览器里。做完会下载 `listening_<名字>.json`，也可以复制文本发回。
- **听者**：母语为普通话，至少 3 名纳入。纳入条件：检查题对 ≥ 8/10，作答 ≥ 90%。

## 预设判定（score.py）

- **每段音频的结论**：取纳入听者的严格多数。“听成正确读音”需要正确读音占严格多数，平票和“都不像”都算没听成。
- **每句的差值**：d = P 听成正确读音 − O 听成正确读音。按字分组做 bootstrap，求 95% CI。
  - **H3**：CPP 少数读音，下界 > 0。
  - **H5**：natural2，下界 > −.05。
- **只报告、不设阈值的**：每名听者单独的结果、Fleiss κ、人工与 ASR 检测器的一致率、只差声调和声韵不同两类分开的结果。

## 用法

```bash
cd experiments/e8_listening
../../.venv/bin/python score.py answers/*.json
```

**注意**：2026-11-07 那次单人盲听用过 TTS-0.6B 的原句音频（O），本次有 9 段 O 音频与那次完全相同。参加过那次的听者，结果要单独看。
